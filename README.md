# Лабораторная работа №7 - Работа с базой данных (SQLite) и CRUD-операции

## Вариант 2 - "Товары" (каталог с фильтрацией по цене)

## Тема работы

Работа с базой данных SQLite в веб-приложении (в моём случае - на Flask) и реализация REST API для выполнения CRUD-операций.

## Нововведения

- **SQLite3** - создание и использование базы данных для хранения информации о товарах;
- **CRUD-операции** - реализация API для создания, получения, изменения и удаления записей:
    - `GET /api/products` - получение каталога товаров;
    - `POST /api/products` - добавление нового товара;
    - `PATCH /api/products/<id>` - изменение количества (и только его) товара на складе по его `id`;
    - `DELETE /api/products/<id>` - удаление товара по его `id`;
- **Фильтрация** - получение товаров в заданном диапазоне цен с помощью параметров `minPrice` и `maxPrice` (оба параметра являются _необязательными_);
- **Валидация данных** - проверка типов, обязательных полей и их допустимых значений перед выполнением операций;
- **Обработка ошибок** - использование стандартных HTTP-статусов (например, `400 Bad Request`, `404 Not Found` и др.) для передачи результатов выполнения запросов;
- **Модульная структура** - разделение работы с базой данных и обработки HTTP-запросов.

## Примеры работы

Получение каталога товаров:

```bash
curl -i -X GET http://localhost:5269/api/products
```

Фильтрация товаров по цене:

```bash
curl -i -X GET 'http://localhost:5269/api/products?minPrice=52&maxPrice=69'
```

Добавление нового товара:

```bash
curl -i -X POST http://localhost:5269/api/products \
    -H 'Content-Type: application/json' \
    -d '{"name": "milk", "price": 100, "stock": 4}'
```

Изменение количества товара на складе по его `id`:

```bash
curl -i -X PATCH http://localhost:5269/api/products/1 \
    -H 'Content-Type: application/json' \
    -d '{"stock": 7}'
```

Удаление товара по его `id`:

```bash
curl -i -X DELETE http://localhost:5269/api/products/1
```

## Результат

Реализовано взаимодействие веб-приложения (опять же, в моём случае - на Flask) с базой данных SQLite. Создан REST API для управления каталогом товаров, поддерживающий основные CRUD-операции, фильтрацию товаров по цене и валидацию входных данных.
